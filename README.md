## The entry

> WARNING: Never shake your own hand. You still owe yourself money.

One line, 65 characters. A deadpan safety notice about the classic
time-travel hazard of meeting your own duplicate self — with the
punchline landing in the last words.

## How it works

`main.py` (Python 3, stdlib only, no network) writes the warning label
to `/output/entry.txt` (and a local copy `entry.txt` for verification).
It is fully deterministic: every run writes the exact same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
